# Digital Clock

A simple digital clock built with HTML, CSS, and JavaScript. It displays the current time and date and updates automatically.

## Features

* Displays the current time
* Displays the current date
* Updates automatically
* Uses a 24-hour time format
* Responsive layout

## Technologies

* HTML5
* CSS3
* JavaScript

## Live Demo

[View Live Demo](https://waheedwana.github.io/digital-clock/)

## What I Learned

While building this project, I practiced working with the JavaScript Date object, getting different date and time values, formatting numbers with padStart(), and updating the page automatically using setInterval(). I also practiced working with arrays to display the correct month and day names.
